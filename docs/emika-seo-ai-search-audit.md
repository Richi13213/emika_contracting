Google's current [Local Business structured-data guide](https://developers.google.com/search/docs/appearance/structured-data/local-business) calls for a physical location and recommends rich detail. EMIKA only has verified city/province/country, so the graph deliberately omits street and postal code; rich-result eligibility must be tested with the [Rich Results Test](https://search.google.com/test/rich-results) once the public URL is live. Markup does not guarantee a rich result. Google's [sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) treats sitemap submission as a discovery hint, not a guarantee.

OpenAI's [crawler documentation](https://developers.openai.com/api/docs/bots) distinguishes OAI-SearchBot for ChatGPT search discovery from GPTBot for training. Production robots rules permit OAI-SearchBot, but public accessibility, bot protection, and indexing still need deployment checks. Crawl permission does not guarantee ChatGPT inclusion.
