## Discrepancies and unknowns

- The legacy inventory calls the current form working, but the source alone cannot prove that the external Lambda currently accepts submissions. Preserve the exact request contract and test locally with a mocked endpoint; a live submission requires a real authorized test contact.
- The current hero says “Fast response mindset” and the contact benefits say “responsive follow-up.” Neither establishes an exact response time. The new copy avoids a time guarantee.
- The existing service image alt text describes scenes. The repository does not establish photo provenance or whether each scene is EMIKA work. Treat them as service illustrations, not portfolio proof.
- The legacy public name `EMIKA Construction` is not confirmed as a legal name. The canonical website domain, street address, hours, social URLs, Google Business Profile URL, certifications, years in business, warranties, broader service area, project client identity, exact project location, project title/scope metadata, and testimonials remain unverified.
- `manifest.json` identifies the selected work stages: feature wall `02 → 03`, service counter `06 → 16`, and upper cladding `07 → 12`. Their viewpoints and focal lengths differ, so the transformation explorer shows one area at a time with a Before/After toggle and crossfade. The accessible overlay slider remains available in code for a future matched-angle pair and is not rendered for this project.
- Gallery photos `11`, `13`, and `15` add entrance/cladding, counter, and vertical interior detail views. The provided `web/` photos were used as sources for metadata-stripped 480/960/1440-pixel WebP variants where the originals allow those widths. The original files stay in the handoff folder.
- `site-content.mjs` now holds published case studies with a public title, conservative summary, nullable client/location, comparison records, image sources/srcsets/crops, and gallery items. `scripts/project-section.mjs` renders project and comparison navigation from those records. It handles no comparisons, one comparison, multiple comparisons, no gallery, and compact or extended galleries without changing markup. Only one verified project is currently published, so the project selector is omitted.
- A third-party logo is visible in some project photographs. The public copy, alt text, filenames, metadata, and structured data intentionally make no client identity claim.
- No deployment target or configuration was found in the repository. Both npm and pnpm lockfiles exist; package manager choice is not verified.
- No analytics integration or privacy/terms pages exist.
