# EMIKA Brand Asset Pack

## Official palette

- Royal Blue: `#123DA6`
- Charcoal: `#1A1A1A`
- Warm Off-White: `#F8F7F3`
- Cool Gray: `#8A9AA6`

## Recommended web files

Copy the contents of `web-ready/brand/` into your application's public brand directory:

- `emika-logo-dark.svg` — Royal Blue + Charcoal; use on light backgrounds.
- `emika-logo-light.svg` — Royal Blue + White; use on dark/photo backgrounds.
- `emika-symbol.svg` — standalone Royal Blue + Charcoal monogram.

## Important note about the SVG files

The approved EMIKA identity originated as an AI-generated raster image rather than an original vector master.
The SVG files in this package are **clean vector traces** rebuilt from that approved visual and normalized to the official flat colors.

They are suitable for web implementation and normal digital use. Before large-format physical production
(vehicle wraps, large signage, embroidery masters, fabrication, etc.), the logo should ideally be professionally
redrawn/checked in Figma, Illustrator, Affinity Designer, or equivalent so its geometry can be treated as a final
master vector artwork.

Do not independently redraw, stretch, skew, recolor, or append “Construction”/“Architecture” to the EMIKA lockup.
